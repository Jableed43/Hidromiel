## 🍯 Dive into the Sweetness: Hidromiel E-commerce Project 🍯

***A labor of learning and creativity!*** This project represents my final endeavor for the Codo a Codo 4.0 course, an initiative proudly supported by the Buenos Aires City Government. It's a **front-end focused e-commerce experience** dedicated to the delightful world of Hidromiel (Honey Mead).

***Crafted with these technologies:***

* **Foundation:** HTML for structure and content.
* **Style & Responsiveness:** CSS for visual presentation, ensuring a seamless experience across **desktop, mobile, and tablet** devices.

**Explore the Meadery Online!** 🔗 [Hidromiel](https://jableed43.github.io/Hidromiel/Web%20principal/Index.html)

**Learn more about the Codo a Codo program:** 🔗 [Codo a codo Site](https://www.buenosaires.gob.ar/educacion/codo-codo)

---

This project showcases my ability to translate a concept into a functional and visually appealing online storefront. By focusing on responsive design, I aimed to create an accessible and enjoyable browsing experience for potential customers, regardless of their preferred device.

The Hidromiel e-commerce site provides a glimpse into the possibilities of online retail, built with fundamental web technologies. It was a valuable learning journey, and I'm excited to share the result!
